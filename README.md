# Sprint Review and Retrospective

## Project Overview
This repository contains my Sprint Review and Retrospective from an Agile development project completed as part of my CS 250 class. The project focused on the process of building a travel booking application using Scrum practices.

## Reflection

### My Approach to Developing Programs & Agile Practices
My approach to development in this project was iterative and centered around Agile principles. Rather than planning the entire system in the beginning, features were developed incrementally and adjusted based on feedback and changing requirements. The Scrum framework helped structure this process through sprint planning, backlog refinement, Daily Scrum, and sprint reviews. 

### Excellence in Teamwork
Being a good team member means practicing structured, role-focused communication. During the shift to wellness travel, there were specific coordination efforts to stay on track. I provided the Product Owner and Tester with specific queries regarding updated acceptance criteria and edge cases rather than sending vague requests for clarification.
